Mô Phỏng Trực Quan Bộ Nhớ Compaction

1. Nhận Tin Nhắn Người Dùng
Trích xuất thực thể, lọc câu hỏi & cập nhật hồ sơ vào User.md (Đè thông tin mâu thuẫn cũ).
2. Tính Toán Token Ngữ Cảnh
Đo tổng tokens = Profile + Messages + Summary hiện tại.
3. Kích Hoạt Compaction (Nén bộ nhớ)
Khi vượt ngưỡng, tóm tắt các đoạn hội thoại cũ & lưu trữ nén, giải phóng context.

Cấu Hình API Key & Tích Hợp AntcoAI LLM Gateway

Khi phát hiện khóa API AntcoAI_LLM_Gateway_API_KEY trong tệp .env, hệ thống tự động ánh xạ cấu hình theo giải pháp trong tệp tham chiếu langchain_llm.py với các bước chuyển dịch quan trọng sau:

Bypass Chặn User-Agent
Sử dụng httpx.Client tùy chỉnh để đính kèm header giả lập User-Agent, tránh việc cổng Gateway của Antco chặn các request từ SDK mặc định của LangChain.
Chế Độ Chạy Thực Tế
Tự động chuyển tiếp luồng xử lý từ mô phỏng sang thực tế, gửi request qua API Gateway tại địa chỉ https://ai-gateway.antco.ai/v1.
Mô hình gemini-3-flash
Sử dụng mô hình thế hệ mới trên cổng Gateway để trích xuất hồ sơ người dùng thông minh, xử lý câu hỏi đính chính và tóm tắt cuộc gọi tối ưu.
Giám Sát Runtime Tokens
Đo lường tokens chính xác trong thời gian thực khi truyền tải và nén thông tin, tối ưu hóa tối đa chi phí gọi mô hình của bạn.
